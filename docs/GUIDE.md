# FO 使用指引（Minecraft 26.3）

面向玩家的准备清单、开启注意事项和常见问题。游戏内每个模块的设置页**底部**也有一份精简版「使用说明」区块（可折叠），内容与本文一致但更短。

- 安装：把 `FO-6.7p36-26.3.jar` 与 Meteor Client 26.3、Fabric API 26.3 一起放进 `mods/`。
- 需要自动寻路时再安装 26.3 版 Baritone（可选，但多个模块没有它就无法工作）。
- 所有模块在 Meteor 的 **FO** 分类下。

---

## 1. FO 鞘翅采集

### 适用场景

**只在末地使用。** 模块没有维度检查，在主世界/下界开启会按末地城坐标乱飞。

### 出发前准备

| 物品 | 要求 | 说明 |
| --- | --- | --- |
| 鞘翅 | 出发前先穿上一件**满耐久**鞘翅 | 背包里可再备一件，模块在拾取/换装阶段会自动穿；破损鞘翅不会自动装备 |
| 烟花 | 放在**快捷栏** | 默认每 2 秒用 1 颗；快捷栏没有会起飞超时 |
| 末影箱 | 推荐携带 | 用于补货和存鞘翅 |
| 潜影盒 | 至少 1 个空盒或可存鞘翅的盒子 | 没有末影箱时靠它存鞘翅 |

「物资列表」默认要求：烟花 ≥4、金胡萝卜 ≥8、不死图腾 ≥3；不足时从末影箱补到目标数量。

### 没有末影箱会怎样

- 只缺物资：跳过补货，继续采集（不会卡住）。
- 需要存鞘翅：背包有可用潜影盒就直接存；背包也没有可用盒子时停止任务并提示。

### 种子

「世界种子」默认 **0**：

- 单人存档：自动读取当前世界种子。
- 联机：**必须手动填服务器种子**，否则定位出来的末地城是错的。

### 开启后会发生什么

- 自动联动开启「FO 自动扔垃圾」（白名单模式）。不需要时手动关掉。
- 「低Y退出」默认开启，Y 低于 **30** 会直接断开服务器，防止掉虚空。
- 背包空格 ≤「背包空格阈值」（默认 3）时，拿到鞘翅后先去存储。

### 其他

- Baritone 可选：没有时无法自动走回降落点，防卡寻路也不可用。
- 黑名单由模块自动维护；设置页底部有「清除黑名单」按钮。

## 2. FO 自动种树

### 用法

1. 开启模块。
2. 用**左键点击**要种树的地面方块，登记种植位（不会真的挖掉方块）。
3. 手持树苗，模块自动种植。
4. 再左键点一次同一位置可取消登记。

### 准备

- 树苗放在**快捷栏**：橡树 / 云杉 / 桦树 / 丛林 / 金合欢 / 深色橡树 / 樱花。
- 「使用骨粉」默认开启，骨粉也要放在快捷栏；没有骨粉会暂停种树并提示。

### 注意

- 只处理已登记的位置，不会自动找地。
- 缺树苗或骨粉时每 5 秒提示一次，不自动补货。

## 3. FO 自动扔垃圾

### 名单模式

- **黑名单**：只丢列表里的物品。
- **白名单**：只保留列表里的物品，其余全丢。默认白名单。

### 工作方式

- 默认每 **20 tick** 扫一遍背包，命中物品一次性全丢（不是一次只丢一个）。
- 「丢弃整组」默认开。
- 「排除快捷栏」默认**关**；想保护常用物品建议打开。
- 「清空后自动关闭」默认关；开启后背包没有可丢物品就自动关模块。

### 联动

被「FO 鞘翅采集」「FO 自动挖沙」「FO 自动挖矿」联动开启时，会切到白名单模式，并按各模块需要补默认列表（例如挖沙保留沙子、挖矿保留石英）。

## 4. FO 自动LogPlus

### 用途

满足任一条件时**自动断开服务器**（不是只停模块），用于保命/保装备。

### 触发条件

低于 Y、护甲耐久低、传送门停留超时、靠近坐标、生命值低、图腾不足、服务器无响应。**默认全部关闭**，按需开启。

### 注意

- 「Y高度」默认 **256**，用「低于Y下线」时记得改成自己的阈值。
- 触发后直接断线。
- 「无响应后重连」默认关；开启后按设定秒数重连。
- 挖矿/鞘翅采集时建议至少开启生命值或图腾下线。

## 5. FO 自动挖沙

### 前置条件

- **必须安装 Baritone**，否则开启后直接报错并关闭。
- 附近 **32 格**内要有潜影盒：
  - 至少一个名字包含「**FO补给**」的补给盒；
  - 至少一个可用的存沙盒（其他潜影盒即可，满了会自动换下一个）。
- 补给盒里要有：够耐久的铲子、所选食物（默认金胡萝卜）、不死图腾。补给时会检查，缺哪项就停模块并提示。

### 挖沙模式

- 「核爆挖掘(Nuker)」默认**关**：关闭时用 Baritone 寻路逐个挖。
- 开启后范围极速挖沙，每 tick 发包上限默认 **30**，防止被服务器踢出。

### 联动

- 开启时强制联动「FO 自动扔垃圾」（白名单，保留沙子）。
- 「联动杀戮光环」默认开。

### 存沙

「自动存沙」默认开；背包空槽少于 **2** 时存到附近潜影盒。

## 6. FO 自动挖矿

### 前置条件（缺一不开）

背包必须同时有：

1. 时运镐
2. 精准采集镐
3. 末影箱
4. 工作台

模块会自己放置和回收这些方块。

### 维度

- **钻石模式**：只能主世界。
- **残骸模式**：只能下界。

选错维度会直接关闭并提示。

### 注意

- 需要 Baritone 才能寻路挖矿；未安装时不会报错，但不会行动。
- 建议同时开启「FO 自动LogPlus」，血量/图腾过低自动下线。
- 主世界检测到深暗之域会自动逃离。
- 镐子耐久低于阈值时，残骸模式会挖石英修复（仅残骸模式）。

### 联动

- 「自动扔垃圾」默认开（白名单，保留石英）。
- 「联动杀戮光环」默认开。

## 7. FO 杀戮光环

### 用法

自动攻击周围符合条件的实体；默认按原版冷却攻击，可开「自定义延迟」。

### 常用设置

- 「武器类型」默认剑；「自动切换」默认开，攻击时切到指定武器。
- 「切换回来」默认关：开启后攻击结束切回原快捷栏槽位。
- 「忽略命名生物」「忽略被动生物」「忽略驯服生物」默认都开，建议保持。

### 注意

- 会被「FO 自动挖沙」「FO 自动挖矿」按设置联动开启。
- 部分服务器禁止自动攻击，使用前确认服务器规则。

## 8. FO 古城战利品搜索

### 前置条件

- 搜索前先填「种子」，再点一次「**应用种子**」（点一次会记住，以后打开模块自动生效）。
- 单人存档可以留空，自动读取当前世界种子；**联机必须手动填服务器种子**。
- 「游戏版本」默认 **≥26.1**。选错版本箱子位置仍然正确，但物品判定会错；连服务器按服务端原生版本选。

### 搜索半径

单位是**区块**，默认 **1000**（也是最小值）。半径越大候选城越多、耗时越长。

### 结果

- 半自动：只负责定位并输出聊天 / Xaero 路径点，不负责赶路和挖方块。
- 没装 Xaero 时聊天结果仍然可用，只是没有路径点。
- 路径点默认写入玩家路径点集，且只在世界地图显示。

### 自动偷取

- 默认开：打开命中的箱子会自动取走附魔金苹果 / 迅捷潜行3。
- 「只偷搜索命中的箱子」默认开。
- 开过的箱子会被记录并跳过，重开模块也不会再加回路径点。

## 9. FO 自动搬运（StashMover）

这是配置最复杂的模块，完整说明见 [`STASHMOVER.md`](STASHMOVER.md)。

### 前置条件

- 双号/三号模式需要多个账号。
- 场地要有：珍珠房活板门 + 正下方水柱、珍珠箱、存储箱、待搬运箱。
- 「珍珠点」表可右键活板门录入，也可靠告示牌识别（告示牌写玩家名，正下方就是珍珠点）。

### 关键注意

- 双号搬运模式的**出生点必须在待搬运箱旁边**，且在「箱子搜索距离」（默认 10 格）范围内。
- 私信默认按 3C 格式「📨 发送者 ➡ 内容」；格式不同就开「自定义私聊正则」。
- 发「拉我N」后等对方「收到N」；对方是机器人不回复时关「等待确认」。
- 「自杀方式」默认发指令，可在设置里改成岩浆。
- 三号模式三个角色只能选一个，选错不会工作。

## 常见问题

**Q：开了鞘翅采集但一直不飞？**
A：先看聊天栏提示。常见原因：没装 Baritone（不影响起飞，但影响走位）、快捷栏没有烟花、没有满耐久鞘翅、世界种子填错。

**Q：鞘翅采集说「跳过补货」？**
A：背包里没有末影箱。只缺物资时会跳过补货继续采集；需要存鞘翅时请准备末影箱或空潜影盒。

**Q：自动挖矿开了没反应？**
A：检查是否装 Baritone、维度是否匹配、背包是否同时有那四样东西。模块缺物品会直接在聊天栏报缺少项。

**Q：自动挖沙一开就停？**
A：附近 32 格没有潜影盒，或没有名字含「FO补给」的补给盒，或补给盒里缺铲子/食物/图腾。

**Q：古城搜索提示「无法获取世界种子」？**
A：联机时客户端拿不到服务器种子，必须手动填「种子」并点「应用种子」。

**Q：模块设置页找不到说明？**
A：说明在设置列表**下方**、「绑定」之前，标题是「使用说明」，点标题可折叠。
